# Ainalaiyn

Клиентская витрина магазина блокнотов. Опубликована через GitHub Pages как статический сайт.

## Обновление каталога

Измените материалы и размеры в локальной панели владельца, затем экспортируйте публичный каталог:

```sh
python3 scripts/export_github_pages.py
git add frontend
git commit -m "Update storefront catalog"
git push
```

Публичная витрина не содержит панель владельца или серверный API. GitHub Pages не запускает Python-бэкенд; локальная панель владельца остаётся отдельной. Кнопка заказа открывает WhatsApp с готовым сообщением.
